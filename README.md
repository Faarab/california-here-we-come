## Prerequisiti

- Python 3.11+
- [uv](https://docs.astral.sh/uv/getting-started/installation/)

## Come eseguire in locale

### Prima volta

```bash
git clone https://github.com/tuousername/california-here-we-come.git
cd california-here-we-come
uv venv
uv sync
source .venv/bin/activate  # Mac/Linux
# oppure
.venv\Scripts\activate     # Windows
```
