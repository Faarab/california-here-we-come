# California Here We Come

## Setup

1. Installa uv: https://docs.astral.sh/uv/getting-started/installation/
2. Installa Python:
   ```bash
   uv python install 3.12
   ```
3. Crea e attiva il virtual environment:
   ```bash
   uv venv --python 3.12
   .venv/bin/activate
   ```
4. Installa le dipendenze:
   ```bash
   uv sync
   ```
